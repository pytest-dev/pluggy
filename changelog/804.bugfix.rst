:meth:`PluginManager.load_setuptools_entrypoints() <pluggy.PluginManager.load_setuptools_entrypoints>` no longer counts, or records the distribution of, an entry point whose plugin was not registered: a plugin which loads to ``None``, or one which a :class:`~pluggy.PluginManager` subclass declines to register, as pytest's does for plugins whose names were merged into ``pytest``. With such a plugin installed, listing plugins through :meth:`~pluggy.PluginManager.list_plugin_distinfo` and :meth:`~pluggy.PluginManager.list_plugin_distributions` raised :exc:`KeyError`.

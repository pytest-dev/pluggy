Keyword-only parameters declared in a hookspec or hookimpl (with ``*``) now emit a :class:`DeprecationWarning`. pluggy currently ignores them: a hookimpl which requests one never receives the value passed by the hook caller, and gets its own default or a :exc:`TypeError` instead. Declare such parameters as regular ones; this will become an error in a future release (`#742 <https://github.com/pytest-dev/pluggy/issues/742>`_).
